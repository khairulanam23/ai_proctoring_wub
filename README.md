# AI Proctoring System

## Purpose
AI-based examination proctoring research and development system designed for modular computer vision and audio analysis capabilities.

## Current Development Environment
- **Language**: Python
- **Containerization**: Docker & Docker Compose V2 (CPU-only local environment)
- **Model Training**: Google Colab (for GPU experimentation and model training)
- **Version Control**: Git & GitHub

## Current Status
**Phase 0 — Development Environment Setup**

The local Docker Engine (v29.7.2) and Docker Compose V2 (v5.5.0) environment has been configured, and project version control initialization is underway.

## Architectural Boundary
> [!IMPORTANT]
> **Moodle Integration Intentional Deferral**: Moodle integration is intentionally deferred to later phases. The current scope of this repository focuses exclusively on AI detection module research, dataset preparation, and standalone model development. No AI detection algorithms or models have been implemented yet.
